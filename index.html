Materiais

  • Arduino Uno/Nano
  • Ponte H L298N
  • 2 Motores DC + rodas
  • 2 sensores de linha IR
  • Chassi com rodinha livre
  • Fios jumper e bateria 6–9V

Montagem

  1. Monte o chassi e prenda os motores.
  2. Fixe a ponte H e o Arduino.
  3. Coloque o sensor na frente do carrinho.

Circuito

  • IN1 → D5
  • IN2 → D6
  • IN3 → D9
  • IN4 → D10
  • Sensores: D2 e D3
  • GND comum entre todos

Código Arduino

// Carrinho seguidor de linha simples
const int sensorEsq = 2;
const int sensorDir = 3;
const int in1 = 5;
const int in2 = 6;
const int in3 = 9;
const int in4 = 10;

void setup(){
  pinMode(sensorEsq, INPUT);
  pinMode(sensorDir, INPUT);
  pinMode(in1, OUTPUT);
  pinMode(in2, OUTPUT);
  pinMode(in3, OUTPUT);
  pinMode(in4, OUTPUT);
}

void loop(){
  int e = digitalRead(sensorEsq);
  int d = digitalRead(sensorDir);
  if(e==1 && d==1) frente();
  else if(e==0 && d==1) esquerda();
  else if(e==1 && d==0) direita();
  else parar();
}

void frente(){
  digitalWrite(in1,1); digitalWrite(in2,0);
  digitalWrite(in3,1); digitalWrite(in4,0);
}
void esquerda(){
  digitalWrite(in1,0); digitalWrite(in2,1);
  digitalWrite(in3,1); digitalWrite(in4,0);
}
void direita(){
  digitalWrite(in1,1); digitalWrite(in2,0);
  digitalWrite(in3,0); digitalWrite(in4,1);
}
void parar(){
  digitalWrite(in1,0); digitalWrite(in2,0);
  digitalWrite(in3,0); digitalWrite(in4,0);
}

Teste e Ajustes

  • Use pista preta sobre fundo branco.
  • Verifique se os sensores estão a 1cm do solo.
  • Troque 0/1 no código se a lógica estiver invertida.
