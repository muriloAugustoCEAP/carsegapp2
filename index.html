Carrinho Seguidor de Linha

Passo a passo completo com design futurista neon

Materiais Necessários

  • Arduino Uno/Nano
  • Ponte H L298N
  • 2 Motores DC + rodas
  • 2 sensores de linha IR
  • Chassi com rodinha livre
  • Fios jumper e bateria 6–9V
  • Adaptador de bateria de 9 volts
  • roda boba
  • Porta pilha
  • parafusos e porcas
  • Suporte de motores

Montagem do Carrinho

  • Primeiro passo pegue o chassi as rodas e 4 suportes coloque um suporte em cada lado do motor.
  • e coloque os parafusos para juntar os suportes com os motores.
  • Segundo passo solde dois fios na ponta da cada motor e númerie os motores para facilitar quando conectar na ponteH.
  • terceiro passo fixe ou cole o arduino e a ponteH
  • quarto passo coloque os dois fios do motor 1 na ponteH depois coloque os dois fios do motor 2 na outra ponta
  • quinto passo fixe os sensores na ponta do carrinho agora pegue um fio conecte no VCC do sensor e no 5V do arduino
  • agora pegue um fio coloque no GND do sensor e no GND do arduino e por ultimo pegue um fio e conecte o na porta
  • analogica do sensor e coloque em uma porta analogica do arduino de sua preferencia

    • Montagem do Circuito

    Exemplo de como conectar as portas no carrinho segdor de linha:

    • M1 → out1
    • M1 → out2
    • M2 → out3
    • M2 → out4
    • Sensor Esq porta analogica → A0
    • Sensor Dir porta analogica → A1

    Código Arduino

    int esq = A0;
int dir = A1;

int IN1 = 5;
int IN2 = 6;
int IN3 = 9;
int IN4 = 10;

void setup() {
  pinMode(esq, INPUT);
  pinMode(dir, INPUT);

  pinMode(IN1, OUTPUT);
  pinMode(IN2, OUTPUT);
  pinMode(IN3, OUTPUT);
  pinMode(IN4, OUTPUT);
}

void frente() {
  digitalWrite(IN1, HIGH);
  digitalWrite(IN2, LOW);
  digitalWrite(IN3, HIGH);
  digitalWrite(IN4, LOW);
}

void parar() {
  digitalWrite(IN1, LOW);
  digitalWrite(IN2, LOW);
  digitalWrite(IN3, LOW);
  digitalWrite(IN4, LOW);
}

void loop() {
  int sE = digitalRead(esq);
  int sD = digitalRead(dir);

  if (sE == 0 && sD == 0) frente();
  else parar();
}

    Testando o Carrinho

    Coloque o carrinho sobre uma linha preta em fundo branco e ligue.

    Ajuste o sensor se necessário.
